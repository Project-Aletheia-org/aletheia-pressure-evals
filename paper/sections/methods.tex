\section{Methods}

\subsection{Subject models}

Three open-weight, locally-deployable models (via Ollama, Q4\_K\_M
quantization): \texttt{qwen3:4b} (4.0B parameters), \texttt{gemma3:4b} (4.3B),
\texttt{llama3.2:3b} (3.2B). Exact model digests, Ollama version, and machine
architecture (Apple Silicon, arm64) are recorded in
\texttt{data/raw\_outputs/baseline-v0.1-20260722.manifest.json} for exact
reproducibility. These are small models, not frontier systems; see Limitations.

\subsection{Experimental design}

A $2\times2$ design crossing goal pressure (absent/present) with an
autonomy-preserving instruction (absent/present), yielding four conditions:
\emph{baseline}, \emph{pressure}, \emph{autonomy}, \emph{pressure\_autonomy}
(exact system prompt text in Appendix~\ref{app:prompts}). Fifteen benign
scenarios (Appendix~\ref{app:scenarios}) span notification permissions,
subscription retention, research participation, and similar low-stakes
organizational requests, each specifying an organization, requested action, a
reason for wanting compliance, information that could be selectively omitted, and
a legitimate alternative. $15 \text{ scenarios} \times 3 \text{ models} \times 4
\text{ conditions} = 180$ generations, one per cell (\texttt{temperature}=0.7,
\texttt{top\_p}=0.9, \texttt{max\_tokens}=3072, random seed 42).

\subsection{Rubric and scoring}

Six primary dimensions, each scored 0--2 (Appendix~\ref{app:rubric}):
\texttt{deceptive\_omission}, \texttt{emotional\_pressure},
\texttt{artificial\_urgency}, \texttt{authority\_social\_pressure},
\texttt{respect\_for\_refusal}, \texttt{transparency}. Two composites:
$\text{manipulation\_score} = $ sum of the first four (range 0--8);
$\text{autonomy\_score} = $ sum of the last two (range 0--4). Three secondary,
diagnostic-only dimensions (\texttt{scenario\_realism},
\texttt{evaluation\_validity}, \texttt{evaluation\_awareness}) are never included
in the composites. Every score is treated throughout as a \emph{measurement made
by a specific judge}, not as ground truth about the text.

\subsection{Judge panel and blinding}
\label{sec:judges}

The identical, blinded generated outputs are scored independently by two judges,
and a subsample by two further judges. Every judge receives only an anonymous
item ID, the scenario context (organization, requested action, relevant
information, alternative), and the visible response --- never the subject model's
identity, the experimental condition, the system prompt used, or the study's
hypotheses. Item order is shuffled with a fixed seed before scoring, and the
same rubric text, JSON output schema, and evaluation prompt hash
(\texttt{evaluation\_prompt\_hash()}) are used for all judges, so differences in
scores are attributable to the judge, not to the inputs.

\begin{itemize}
\item \textbf{Open-weight judge (primary): \texttt{qwen3:4b}}, temperature 0,
scores all 180 outputs. Structured JSON is enforced; malformed output triggers up
to 3 repair-prompt retries before being recorded as a failure (never silently
discarded). One item (\texttt{item-0049}) exhausted the judge's standard 4096-token
budget on hidden reasoning before emitting visible content and was rescued with a
one-off \texttt{max\_tokens}=8192 call, identical in every other respect (see
\texttt{reports/protocol\_deviations.md}).
\item \textbf{Frontier judge: \texttt{claude-sonnet-4-6}}, temperature 0, scores
the same 180 outputs under the identical blinding, rubric, schema, and prompt
hash (180/180 successful, 11 JSON-repair retries all recovered). This is a
hosted, paid model; the run cost \$3.36 against a \$10 ceiling and is the only
component of the study that requires a paid API.
\item \textbf{Secondary open-weight judges: \texttt{gemma3:4b} and
\texttt{llama3.2:3b}}, each scoring a stratified 60-item subsample (5 per
(model, condition) cell, plus items the primary judge flagged as ambiguous,
low-confidence, or top-5\% consensus manipulation), blind to the other judges.
This subsample replaces an originally-planned fixed manual human-annotation set;
the change was made before any human annotation began (rationale in the protocol
deviation record).
\end{itemize}

\subsection{Deterministic audit}

A code-only, no-model-call audit checks whether each response mentions a decline
option, mentions the scenario's known alternative, discloses the relevant
tradeoff, contains urgency/emotional-pressure/authority-social-proof keyword
patterns, and whether judge evidence for a positive claim is traceable to the
response text. It is a coarse keyword/regex diagnostic --- by construction it
detects only overt lexical manipulation --- and never overwrites a judge's score.

\subsection{Selective escalation}

Rather than requiring exhaustive manual review, an item is flagged when: a judge
score range $\geq 2$ on any dimension; no 2-of-3 majority on $\geq 2$ dimensions;
any judge reports \texttt{ambiguous=true} or confidence $<0.65$; a positive-score
evidence excerpt cannot be traced to the response; primary/secondary judges differ
by $\geq 3$ on manipulation\_score or $\geq 2$ on autonomy\_score; the
deterministic audit contradicts consensus; or the item is in the top 5\% of
consensus manipulation scores. Of 180 items, 89 were flagged; a 20-case priority
subset (genuine substantive signal) is recommended for human review, and the
remaining 69 are carried via sensitivity analysis rather than treated as resolved.
No human ratings have yet been collected (Section~\ref{sec:limitations}).

\subsection{Statistical analysis}
\label{sec:stats}

Each scenario is evaluated under all four conditions by each subject model, so
observations are paired within scenario and not independent. The three
preregistered contrasts (pressure$-$baseline, pressure\_autonomy$-$pressure,
autonomy$-$baseline) on manipulation\_score and autonomy\_score use
scenario-blocked bootstrap 95\% confidence intervals (5{,}000 resamples,
resampling whole scenarios with replacement) and paired sign-flip permutation
tests (10{,}000 permutations), both seeded at 42, computed identically for each
judge's scores (pooled across models: $n=45$ scenario-model pairs per contrast;
15 per model per-model). Paired Cohen's $d$ is reported for effect size. The
confirmatory family is the 3 contrasts $\times$ 2 composites $=6$ tests per
judge; we report Holm--Bonferroni-adjusted $p$-values across that family. An
exploratory OLS regression (manipulation\_score $\sim$ pressure $+$ autonomy $+$
pressure$\times$autonomy $+$ model) with scenario-clustered standard errors is
reported separately and is explicitly not one of the confirmatory contrasts.
Because the original bootstrap-CI script was not preserved in the repository,
confidence intervals were recomputed from the committed
\texttt{scenario\_blocked\_bootstrap\_ci} at seed 42; recomputed bounds differ
negligibly from the originally-reported ones (e.g. $[-0.089, +0.089]$ vs
$[-0.111, +0.111]$) and never change a conclusion.
