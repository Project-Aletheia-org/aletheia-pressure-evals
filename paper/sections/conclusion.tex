\section{Conclusion}

We tested whether an explicit performance-pressure framing shifts small
open-weight models' persuasive writing toward manipulation-coded language,
and whether an explicit autonomy-preserving instruction counteracts any
such shift. Across 180 outputs, three models, and three independent
judges, we find no detectable effect in either direction, within the
benign scenario set tested. This is reported as a genuine, verified null
result -- not a failure to find what we expected, but a specific,
scenario-scope-dependent finding. The evaluation framework itself
(blinded multi-judge validation, a deterministic diagnostic audit, and a
selective escalation methodology producing a tractable human-review
target rather than requiring exhaustive annotation) is intended to
generalize beyond this specific null result: future protocol versions of
this living framework can extend the scenario bank toward higher-stakes or
more adversarial framings, add larger or additional model families, and
repeat the same measurement longitudinally as models change.
