\section{Reproducibility Statement}
\label{sec:reproducibility}

Repository: \url{https://github.com/Project-Aletheia-org/aletheia-pressure-evals}
(public, MIT licensed). All raw generation and evaluation records
(including preserved failed attempts), run manifests (model digests,
Ollama version, machine architecture, random seeds, generation
parameters), the escalation review, agreement statistics, and this
manuscript's source are committed to the repository. Exact reproduction
commands:

\begin{verbatim}
uv sync
uv run pressure-evals check
uv run pressure-evals generate --run-id baseline-v0.1-20260722
uv run pressure-evals evaluate --run-id baseline-v0.1-20260722
uv run pressure-evals evaluate-sample --run-id baseline-v0.1-20260722 \
    --judge-model gemma3:4b
uv run pressure-evals evaluate-sample --run-id baseline-v0.1-20260722 \
    --judge-model llama3.2:3b
uv run pressure-evals escalate --run-id baseline-v0.1-20260722
\end{verbatim}

All four generation/evaluation commands are resumable and require no paid
API access. The external-judge validation extension
(Section~\ref{sec:external-judge}) is not yet a CLI subcommand; it is run
as a standalone script (\texttt{src/pressure\_evals/external\_judge.py})
and requires an Anthropic API key and its own \$10 cost ceiling, both
set explicitly by the operator rather than defaulted. Generation itself
is stochastic (temperature 0.7); exact response text will differ on
rerun, though the pipeline, scenario order, and analysis methodology are
fully deterministic given the same generated data. One evaluation item
required a documented one-off rescue outside the standard CLI path (see
\texttt{reports/protocol\_deviations.md}). Full computational cost
accounting (wall-clock vs. continuous compute time, since this run was
manually interrupted and resumed several times) is in
\texttt{reports/computational\_costs.md}.

\paragraph{Disclosure.} This manuscript and the accompanying codebase were
produced with AI-assisted coding and drafting (Claude, Anthropic) under
direct human direction and review; all reported statistics were
independently recomputed from the saved raw data before inclusion in this
manuscript.
